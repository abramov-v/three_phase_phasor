# Three-Phase Phasor Animation

A small Python visualization of a balanced three-phase system.

## Stack

- Python 3.10+
- NumPy
- Matplotlib

## Run

```bash
pip install numpy matplotlib
python main.py
```

## Features

- Three rotating voltage phasors with 120° phase displacement
- Current phasors for resistive, inductive, and capacitive loads
- Configurable voltage, current, and frequency
- Active, reactive, and apparent power calculation
- Power factor calculation

Change the parameters in `main.py` to explore different operating conditions.
